# Content model — WOMEN Coiffure
Source de vérité : src/content.config.ts.
- salons (md, frontmatter seul, src/content/salons/<salon>.md) : order, name, shortName, team[{name, specialty}], address{streetAddress, postalCode, addressLocality}, mapsUrl, openingHours[{days[lundi…dimanche], opens, closes}], reviews{google, planity : {rating, count}}, bookingUrl (Planity), photo + photoAlt + photoPosition?, gallery[{image, alt, caption, size normal|big|wide, position?}]. Rendu : carte de réservation, galerie, lien du pied de page, llms.txt, nœud JSON-LD HairSalon.
- actus (md, src/content/actus/<slug>.md) : title, date (AAAA-MM-JJ ou AAAA-MM), tag, link{label, href}? ; corps = texte de l'actu. Tri : plus récente d'abord, un mois seul passe avant les jours du même mois, puis ordre alphabétique du fichier.
- realisations (md, src/content/realisations/<slug>.md, photos dans <slug>/) : title, date (comme actus), salon? (référence à la collection salons), before + beforeAlt, after + afterAlt ; corps = texte court. Tri : plus récente d'abord. Section de l'accueil rendue seulement si la collection n'est pas vide.
- accueil (md, fichier unique src/content/accueil/accueil.md) : title, updatedDate, hero{eyebrow, title, titleEmphasis, lead, ctaLabel, portrait, portraitAlt, caption}, stats[4]{value, label}, salons{eyebrow, title, intro, teamNote}, founder{eyebrow, title, photo, photoAlt, bio[chapeau, puis paragraphes ou {quote}], facts[]}, newClient{eyebrow, title, text, cta}, visit, realisations{eyebrow, title, intro}, events{eyebrow, title, intro, photo?+photoAlt, approach{title, text}, journey{title, steps[{title, text}], note}, party{title, services, guests[]}, occasions[], conditions[], team{names, detail}, pricing, gallery, booking}, instagram, news{eyebrow, title, intro}, shop{eyebrow, title, text, cta}.
- pages (md) et landings (mdx) : collections du socle, vides sur ce site.
- settings/site.json : name, shortName, description, whenToUse, tagline, nav, bookingCta, callLabel, organizationName, founder{name, jobTitle, description}, contact{phone E.164, phoneNote, contactType}, social{twitter, linkedin, instagram[{handle, url}]}, faq — validé par Zod dans src/lib/site.ts.
Règles : bumper updatedDate de accueil.md à chaque modification de l'accueil (lastmod sitemap = max(updatedDate, dernière actu)).
